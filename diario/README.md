# 📝 Diário de estudos

Anotações das manhãs de estudo, **um arquivo por dia**, dentro da pasta do tema.
A revisão da noite não gera arquivo: é a releitura destas anotações e dos vídeos do dia anterior.

## 📂 Pastas e padrão de nome

| Pasta | Nome do arquivo | Exemplo |
|---|---|---|
| `sql/` | `SQL-DD-MM-AAAA.md` | `SQL-02-10-2026.md` |
| `mcp/` | `MCP-DD-MM-AAAA.md` | `MCP-05-10-2026.md` |
| `api-rest/` | `API-DD-MM-AAAA.md` | `API-06-10-2026.md` |
| `cypress/` | `CYPRESS-DD-MM-AAAA.md` | `CYPRESS-07-10-2026.md` |
| `ci-cd/` | `CICD-DD-MM-AAAA.md` | `CICD-08-10-2026.md` |
| `git/` | histórico do dia 01/10 (tema fora do plano) | `COLA-GIT.md` |

Para começar o dia: copie o [modelo](_modelo.md) para a pasta do tema e renomeie com a data.
