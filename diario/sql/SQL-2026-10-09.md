# <BANCO DE DADOS> — 09/10/2026

## ☀️ O que estudei (09:30–11:00)
- BANCO DE DADOS: Coleções de dados que possuem características separadas, mas que estão organizadas em locais específicos (tabelas).
- TABELAS: Guardam dados de coisas que possuem características semelhantes. (conjunto de registros).
- REGISTROS: São locais onde são armazenados informações sobre determinados elementos dentro do banco de dados (armazenados por campos).
- CAMPOS: São os dados dos elementos.
- TIPOS PRIMITÍVOS: 
    - Numérico 
        - Inteiro: TinyInt, SmallInt, Int, MediumInt, BigInt 
        - Real: Decimal, Float, Double, Real
        - Lógico: Bit, Boolean
    
    - Data/Tempo: Dagte, DateTime, TimeStamp, Time, Year

    - Literal
        - Caractere: Char, VarChar
        - Texto: TinyText, Text, MediumText, LongText
        - Binário: TinyBlob, Blob, MediumBlob, LongBlob
        - Coleçao: Enum, Set

    - Espacial: Geometry, Point, Polygon, MultiPolygon

## 🛠️ O que pratiquei / entreguei (arquivos)
- CRIAÇÃO DO BANCO DE DADOS COM COMANDOS
- Criei o Banco de Dados dentro do DBeaver, ele se chama loja_qa
    - CREATE DATABASE: Comando utilizado para criar um banco de dados (CREATE DATABASE *nome do banco*;).
    - CREATE TABLE: Comando para criar tabelas (CREATE TABLE *nome da tabela*;). - é necessário colocar os campos dentro da tabela CREATE TABLE:

    CREATE TABLE *nome da tabela*(
        tabela 1 tipo_primitivo (quantidade de caracter ou n),
        tabela 2 tipo_primitivo (quantidade de caracter ou n),
        tabela 3 tipo_primitivo (quantidade de caracter ou n),
        tabela 4 tipo_primitivo (quantidade de caracter ou n)

    - USE *nome do banco*: para abrir um banco de dados
    - DESCRIBE: Para descrever a tabela *DESCRIBE *nome da tabela*;
    )
