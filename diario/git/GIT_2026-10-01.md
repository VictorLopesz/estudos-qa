## ☀️ O que estudei (09:30–11:00)
- O que é um repositório?
    É onde podemos guardar o código que estamos criando, nele podem ser guardados alterações realizadas no código e trabalhar de forma conjunta com outros pessoas. O repositório guarda o código e todas as versões (alterações) dele.

- O que é um commit?
    É uma versão das alterações salva no histórico local, com mensagem, autor e data. Só vai para o Github depois do push.

- Quais são as 3 áreas do Git e por onde um arquivo passa até virar commit?
    Pasta de trabalho, preparação e repositório local.

- Para que servem git status, git add, git commit e git log?
    - git status: verifica quais arquivos mudaram e quais estão no staging
    - git add: adiciona um determinado arquivo ou diretório para ser commitado
    - git commit: salva uma determinada alteração no histórico local
    - git log: mostra a lista de commits (autor, data, mensagem)
