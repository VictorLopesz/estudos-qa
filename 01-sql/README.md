# 01 · SQL (PostgreSQL) + Docker

## Objetivo
Consultar e validar dados como QA: SELECT, JOIN, GROUP BY, subqueries, massa de dados e validação no banco depois de testes de API e de tela.

## 📂 Estrutura
- `docker-compose.yml` — PostgreSQL (e depois PostgREST) no Docker
- `schema.sql` / `seeds.sql` — tabelas e massa de dados
- `exercicios/` — consultas numeradas (`01-select.sql`, `02-joins.sql`, ...)
- `scripts/` — geração de massa com Faker

## ▶️ Como rodar
> Preencha quando criar o docker-compose (dia 02/10).
